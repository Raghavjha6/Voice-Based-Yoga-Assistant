🧘 Voice-Based Yoga Assistant

AI Powered Pranayama Recognition System

Version : 1.0 | Course : MCA Major Project | University : MAKAUT

📌 Project Overview

Voice-Based Yoga Assistant is an Artificial Intelligence based application developed to recognize different Yoga Pranayama techniques from voice recordings.

The application detects Om chanting and Bhramari Pranayama in real-time, stores every session inside a SQLite database, and provides analytics through a Flask dashboard.

🎯 Objective
  • Recognize yoga pranayama using only voice.
  • Perform real-time prediction using Machine Learning.
  • Automatically record and analyse every session.
  • Maintain practice history and statistics.
  • Provide a low-cost and contactless yoga assistant.
❓ Why This Project?

Traditional yoga monitoring generally depends on cameras, wearable devices or trainers.

This project demonstrates that pranayama techniques can be recognized using only voice signals, making yoga monitoring inexpensive, portable and accessible.
